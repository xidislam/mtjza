# AGENTS.md

MTJZA online store (gifts, abayas, modest fashion; Bangladesh). TanStack Start + React 19 + Tailwind 4, deployed on Netlify. Orders persist in Netlify Database via Drizzle ORM.

## Layout

```
db/
  schema.ts            # Drizzle schema (orders table). Source of truth for the DB.
  index.ts             # drizzle({ schema }) client using drizzle-orm/netlify-db
netlify/database/migrations/   # Generated by drizzle-kit. Never hand-edit applied migrations.
public/img/            # Product + hero photography (AI-generated placeholders, replaceable)
src/
  data/products.ts     # Product catalog + categories (English + Bengali labels)
  lib/store.ts         # Shop config: WhatsApp/payment numbers, delivery zones & fees, taka(), imageUrl(), whatsappLink()
  lib/cart.tsx         # CartProvider/useCart — client cart persisted to localStorage
  server/orders.functions.ts  # placeOrder / getOrder server functions (zod validated)
  components/          # Header, Footer, Logo, ProductCard, CartDrawer, CheckoutModal
  routes/
    __root.tsx         # Shell: fonts, meta, CartProvider, Header/Footer, CartDrawer
    index.tsx          # Home: hero, category tiles, catalog (search params ?category=&q=)
    products/$slug.tsx # Product detail
    order/$code.tsx    # Order receipt (code like MTJ-AB12CD)
```

## Conventions & decisions

- Prices are always recomputed on the server from `src/data/products.ts`; the client only sends product IDs and quantities.
- Delivery fee logic lives in `deliveryFee()` in `src/lib/store.ts` and is shared by the checkout UI and the server.
- Phone numbers are normalised to `01XXXXXXXXX` server-side; `getOrder` returns a masked phone and no address, since receipts are reachable by order code alone.
- bKash/Nagad are manual "Send Money" + Transaction ID — there is no payment gateway yet.
- Images are always rendered through `imageUrl()` (Netlify Image CDN, webp) — never reference `/img/*.png` directly in `<img>`.
- Bilingual copy: Bengali strings use the `font-bangla` class (Hind Siliguri).
- Theme colours are Tailwind tokens defined in `src/styles.css` (`plum-*`, `blush-*`, `cream-*`).
- Schema changes: edit `db/schema.ts`, then `npx drizzle-kit generate --name <verb_description>`. Never run migrate/push.
- `drizzle-orm` and `drizzle-kit` must stay on the `@beta` line (Netlify adapter).
